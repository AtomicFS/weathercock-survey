# Limits of anonymity

Version 0 is a proof of concept. It runs only in development mode.

> [!WARNING]
> Version 0 is not anonymous. Do not use it with real people or real answers.

## Development mode

- The sign-in has no password. Each person who can open the page can type any user ID and submit as that person.
- The server uses plain HTTP, not HTTPS. The server accepts connections only from the same computer.

## What version 0 shows

Version 0 stores data in the same way as version 1:

- The server sees the user ID and the answers together when a person submits.
- The server stores the answers as counters and as separate text answers. Nothing links the answers of one submission.
- Until the planned end of a period, the database records who submitted. At the planned end, the server deletes these records. If the server is stopped at the planned end, it deletes them at its next start.
- Version 0 makes no backups.
- The results page shows a period only after its planned end, and only if it has a minimum number of submissions (k).
  At the planned end, the server deletes the answers of a period with fewer submissions.
